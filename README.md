**Northwind Traders – Business Analysis using Power BI**

This project focuses on analyzing Northwind Traders' business data using Microsoft Power BI. It includes data loading, data cleaning, data modeling, DAX measures, and interactive dashboard development.

The dashboard provides insights into sales performance, product categories, customer distribution, order trends, freight costs, and employee performance.

**Key Features:**
- Data Loading and Cleaning
- Data Modeling and DAX Measures
- Interactive Power BI Dashboard
- Sales and Product Category Analysis
- Customer and Regional Analysis
- Employee Performance Analysis
- Business Insights and Recommendations

**Tools Used:** Microsoft Power BI, Power Query, DAX

**Objective:** To transform raw business data into meaningful insights and provide data-driven recommendations for better business decisions.
